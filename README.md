# BlockBot

A web-based, block-based programming environment where pre-college students can program robots using visual blocks. The robot can be simulated (maze/field with obstacles) or connected to a real robot (Sphero, etc.). Students learn programming through hands-on, immediate visual feedback.

## Features/Needs

• Visual block-based editor (drag-and-drop blocks using Blockly framework)
• Core programming blocks: move forward/backward, turn left/right, repeat loops, if/else conditionals
• Robot simulator with maze/field (visual representation of robot movement)
• Run program button (execute code and see robot move)
• Stop/reset program
• Simple maze or field environment with obstacles & finish line
• Save/load programs
• Responsive web interface
• AI hints & adaptive difficulty (ML difficulty classifier)

## Workflow

Do not push directly to the main branch

### Starting a Task

1. Pull the latest changes:

```bash
git checkout main
git pull
```

2. Create a feature branch:

```bash
git checkout -b feature/taskname
```

### Saving Your Work

```bash
git add .
git commit -m "changes that you did"
git push -u origin feature/taskname
```

### Finishing a Task

Create a Pull Request from your feature branch into the main branch for review before merging.
