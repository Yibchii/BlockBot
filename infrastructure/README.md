# Infrastructure

This folder contains files and information related to the tools and infrastructure used for our Senior Capstone project.

## Purpose

The purpose of this folder is to organize the technical setup needed to support the development, testing, and deployment of the project.

## Infrastructure Areas

This folder may include information or configuration files related to:

- Development environment setup
- CI/CD pipelines
- GitHub Actions
- Testing infrastructure
- Cloud infrastructure and deployment
- Databases and data storage
- Monitoring and logging
- APIs and external services
- Security and secrets management
- Troubleshooting and setup instructions

## CI/CD

GitHub Actions may be used to automate processes such as:

- Running tests
- Building the application
- Checking code changes
- Supporting deployment

Workflow files will be stored in:

`.github/workflows/`

## Security

Passwords, API keys, access tokens, credentials, and other sensitive information should never be committed to this repository.

Environment variables and GitHub Secrets should be used when sensitive configuration information is required.

## Documentation

Infrastructure-related setup instructions should be updated as tools, configurations, or deployment processes change throughout the project.

## Team Responsibility

The Tools & Infrastructure group is responsible for helping maintain the development tools and infrastructure needed by the project team.
